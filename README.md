# 鼠标点击测试

打开 `dist/index.html` 即可离线使用，无需安装或联网。页面的「保存离线网页」按钮可以另存为一个独立 HTML 文件，方便拷贝到其他电脑复测。

单击测试按每隔约 1 秒单击、手动计数、结束测试、填写手指实际按下次数的顺序进行。计数不会自动到 20 停止，避免额外点击使测试提前结束。鼠标和触控板分组测试。

按住测试要求每次持续按住 3 秒，建议重复 5 次；提前松开只标记「未达目标」，窗口切换标记「记录中断」，都不会自动判定硬件损坏。

只通过 `pointerdown` 统计按下次数，`pointerup` 记录按住时长；`dblclick` 只保留为辅助事件，不另增加点击次数。浏览器收到的事件不是 USB/HID 原始报告，网页无法单独排除驱动、系统、固件或主动双击。

结束的测试及用户补充的实际次数保存在当前浏览器的本地存储中，最多 12 组。支持导出文字报告及 JSON 事件记录。无后端和外部资源请求，测试记录不上传。

`verify-browser.cjs` 使用工作区随附的 Playwright 执行隔离浏览器验证。验证场景涵盖慢速单击、双击不重复计数、左右中键、按住、窗口切换、导出、历史、离线运行和窄屏布局。验证运行生成的文件不会进入托管产物。

如果浏览器支持 `document.modelContext`，页面提供只读的 `read_mouse_test_results` 工具；普通浏览器不支持时正常使用页面。当前验证浏览器不支持该接口，实际 WebMCP 注册验证不可用。
